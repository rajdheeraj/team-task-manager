# 🚀 Team Task Manager (Full-Stack)

A full-stack web application where teams can create projects, assign tasks, and track progress with role-based access control.

---

## 🌐 Live Demo

Frontend: https://team-task-manager-kohl-iota.vercel.app
Backend: https://team-task-manager-production-08a2.up.railway.app

---

## 🛠️ Tech Stack

**Frontend**

* React (Vite)
* Axios
* React Router

**Backend**

* Node.js
* Express.js
* MongoDB (Mongoose)

**Deployment**

* Frontend: Vercel
* Backend: Railway
* Database: MongoDB Atlas

---

## ✨ Features

* 🔐 User Authentication (Signup/Login with JWT)
* 👥 Role-based Access (Admin / Member)
* 📁 Project Creation & Team Management
* ✅ Task Creation, Assignment & Status Tracking
* 📊 Dashboard (Total, In-progress, Completed, Overdue tasks)
* 🔄 Real-time Status Updates

---

## ⚙️ Setup Instructions

### Backend

```bash
cd express-starter
npm install
npm run dev
```

### Frontend

```bash
cd client
npm install
npm run dev
```

---

## 🔑 Environment Variables

### Backend (.env)

```
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
```

### Frontend (.env)

```
VITE_API_BASE_URL=your_backend_url/api
```
